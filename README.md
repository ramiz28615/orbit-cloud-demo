# Orbit Cloud — etkileşimli prototip

Bu depo, Orbit Cloud arayüzünün statik ve etkileşimli bir ürün demosunu içerir.

## Deneme

`index.html` dosyasını bir tarayıcıda açabilir veya GitHub Pages üzerinden görüntüleyebilirsin. Demo panosundaki projeler, dağıtımlar, analitikler ve alan adları örnek verilerdir.

## Demo sınırları

- Google ile giriş gerçek OAuth bağlantısı kurmaz; yalnızca demo panosunu açar.
- E-posta ve parola formu sunucuya gönderim yapmaz; tarayıcıda demo davranışı gösterir.
- Proje, dağıtım ve alan adı düğmeleri gerçek Git/Vercel/API/DNS işlemi yapmaz.
- Ürün adı ve ekranlar prototip amaçlıdır; gerçek bir hizmet taahhüdü değildir.

Bu site statiktir; kullanıcı hesabı, sunucu tarafı API veya gerçek dağıtım backend'i içermez.
